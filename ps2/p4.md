# PHASE 4 – FACULTY MODERATION, INTEGRATION AND FINAL DELIVERY

Continue from the existing EDUCORE AI PS2 codebase.

Preserve all existing Phase 1, Phase 2 and Phase 3 features.

Your task is to complete the faculty moderation workflow, integrate PS2 with the shared EDUCORE platform and prepare the final hackathon demonstration.

## 1. Faculty moderation

Implement the faculty evaluation review screen.

Show:

- Student name and student ID.
- Assessment and question.
- Original student answer.
- Reference answer.
- Rubric criteria.
- AI suggested marks.
- Criterion-level evidence.
- Feedback.
- Maximum marks.

Allow faculty to:

- Accept suggested marks.
- Modify final marks.
- Enter moderation reason.
- Save final evaluation.
- Finalize results.

Validate that final marks remain between zero and maximum marks.

## 2. Preserve moderation history

Implement:

backend/routes/moderation.py

POST /api/ps2/evaluations/{evaluation_id}/moderate

Store:

- evaluation_id
- reviewed_by
- original_suggested_marks
- final_marks
- moderation_reason
- reviewed_at

Never overwrite the original AI score.

Maintain a complete moderation audit history.

## 3. Student results

Build a student result page.

Display:

- Final marks.
- Maximum marks.
- Criterion-wise breakdown.
- Correct concepts.
- Missing concepts.
- Constructive feedback.
- Evaluation status.

Support the statuses:

- ai_suggested
- faculty_reviewed
- finalized

Do not show an unapproved AI score as a finalized result.

## 4. EDUCORE integration

Keep all code within:

EDUCORE-AI/ps2/

Do not create a separate student identity system.

/api/ps2

{
  "success": true,
  "module": "ps2",
  "student_id": "STU001",
  "data": {},
  "message": "Operation completed"
}

Document the fields required by PS1 and PS3.

Provide a weak-topic endpoint for PS1 integration:

GET /api/ps2/weak-topics/{student_id}

Only expose authorized academic information.

Document the performance and assessment fields that PS3 may consume.

Do not assume other modules' database tables already exist.
