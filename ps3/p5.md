### Required functionality

- Login.

- User account management.
- Active/inactive account status.

- Secure authentication error handling.
- Session expiration.

### Important security requirements

- Never store plaintext passwords.

- Do not log passwords, tokens or session secrets.

# 6. PREVENT CONCURRENT COUNSELLOR EDITING CONFLICTS

Phase 4 identified that simultaneous counsellor edits could overwrite each other.

Implement optimistic concurrency control.

Use a version field or another suitable mechanism.

### Requirements

- Every intervention update must check the current version.
- Successful updates increment the version.
- Stale updates must be rejected.
- Return HTTP 409 for conflicting changes.
- Provide a meaningful error message.
- Allow the frontend to refresh the latest intervention state.
- Do not silently overwrite another counsellor's update.

Create tests with two simulated users attempting to update the same intervention.
